## Lottie

### Props

| Property | Description | type | default |
| --- | --- | --- | --- |
| type | loading icon type | circular | spinner | `circular` |
| direction | direction of icon and text | horizontal | vertical | `horizontal` |
| icon | custom loading icon | tsx.Element | `-` |
